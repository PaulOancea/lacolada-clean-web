# LaColada Local

Build a modern, simple, and professional website for a self-service laundromat called Lavandería LaColada Teruel.

Overall Style

The website should feel like it was designed by a local web designer, not generated by AI.

Avoid:

 flashy animations

 gradients everywhere

 oversized rounded cards

 excessive icons

 futuristic UI

 AI-looking layouts

Instead create:

 clean whitespace

 modern typography

 subtle shadows

 simple blue and white color palette

 a trustworthy local business feel

 responsive design

 fast loading

 elegant but minimal

The design should resemble a high-quality small business website.
